# Visual Design System (DESIGN.md)

本ファイルは、AIエージェントがUIコード（HTML, CSS, React, など）を生成する際に参照するデザイン仕様書です。UIを構築する際は、必ずこのルールに従ってください。

対象業種：カフェ（自家焙煎コーヒー＋スイーツ＋テラス／個人経営〜小規模店舗）
想定店舗例：「KOMOREBI COFFEE（木漏れ日珈琲）」※ポートフォリオ用の架空店舗

## 1. トーン＆マナー
* **ブランドイメージ:** 明るい、やさしい、上品、ほっと落ち着く、写真映え・Instagram映え
* **コアバリュー:** 「ゆっくり過ごす一杯と一皿の時間」を、説明よりも写真と余白で伝えること。情報量より空気感を優先する
* **参考にした要素（構造とトーンのみ踏襲。ロゴ・写真・文言はコピーしないこと）:**
  * 参考A（明るい洋菓子ブランドサイト）
    * トップ: 白基調、ロゴを左上に縦積みで固定、上部だけ大きく丸く切り抜いたアーチ状の写真、右側に縦並び・右揃えのナビ、右下の回転する丸バッジ、細く字間の広いキャッチコピー
    * 下層: 中央揃えの短い行で組んだ理念ページ（スクロールで文字が濃くなる）、枠なしの正方形フォトタイルの商品一覧と細い円形アウトラインCTA、ブランドのスウォッシュ（曲線）を巨大に拡大したフッター
    * スマホ: ロゴは縮小しても全要素（Since・スウォッシュ）を残して左上に置き、右上は「Menu」の下線付きテキストだけにする。写真は左右ほぼ余白なしで表示する
  * 参考B（老舗菓子の公式オンラインショップ）
    * トップ: 全画面の落ち着いた色調の写真、中央配置の縦書きロゴ、アイコン付きの最小限ナビ、左端の「Scroll」表示、右下のスライダードット
    * 下層: 左端に固定した縦書きロゴ、クリーム色の円形アイコンボタンのヘッダー、右上角のお知らせタブ、日付＋タグ＋タイトルのお知らせリスト、左テキスト＋右に大きな商品写真の商品紹介、クリーム色のソフトボタン、罫線で情報を整理したフッター
    * スマホ: 画面上部に固定するクリーム色の4分割タブバー、右下に固定する白い円形の「MENU」ボタン、右上に固定するクリーム色の「Online Shop」ピル、全画面写真に白い明朝体タイトルとパンくずを重ねた下層ページの導入、サムネイル左＋商品名右の商品リスト
* **下層ページの方針:** お知らせ・フッターなどの情報ページは、写真や装飾を足さず「余白・細い罫線・クリーム色」だけで整える。トップは写真で魅せ、下層は静かに読ませる、というメリハリをつける
* **写真ディレクション:** 写真がデザインの8割を決める。以下のトーンで統一する。
  * ヒーローA用（明るい）: ハイキー（白っぽく明るい）、柔らかい自然光、浅い被写界深度（背景をぼかす）、ケーキやカップに寄った構図
  * ヒーローB・C用（ムーディー／ライフスタイル）: ローキー〜ミディアムキー、木の机・窓辺・一輪挿しなど、生活感のある静かな情景。彩度は控えめ。ヒーローCでは「窓辺で本を読みながらお茶を飲む人」のような、手元・後ろ姿・横顔中心のシーンを使う
  * 商品写真（一覧・商品紹介用）: 明るいウォームホワイトの背景で、商品を皿ごと中央に配置。足元にやわらかい影を落とし、背景が均一なスタジオ撮影とする
  * 共通: 彩度を上げすぎない。人物は顔よりも「手元（フォークを持つ手、ドリップする手）」を優先する

## 2. カラーパレット (Colors)
白に近いミルク色をベースに、深煎りコーヒーのブラウンを主役とし、木漏れ日を思わせるゴールドと苺のレッドを少量だけ差し色に使う。指定された役割（トークン）に応じて、以下のカラーコードを厳密に使用してください。
* **Primary (ブランドカラー・深煎りブラウン):** `#4A2C21` / `--color-primary` (例: 深煎り豆・チョコレート。ロゴ、見出し、ボタンに使用)
* **Secondary (アクセント・木漏れ日ゴールド):** `#A8964A` / `--color-secondary` (例: ロゴの楕円枠・細い罫線・アイコン。**明るい背景の上では文字色に使わない**。文字に使ってよいのは Background Dark 上のみ)
* **Accent (差し色・苺レッド):** `#D22A2E` / `--color-accent` (例: NEWチップ、ロゴのスウォッシュ、回転バッジ、円形CTAの点。1画面あたり1〜2箇所まで。**例外:** フッターAのブランドモチーフ（巨大なスウォッシュ）は1箇所のみ許容)
* **Cream (ソフトボタン・タブバー・アイコン円の背景):** `#F0E6CC` / `--color-cream` (例: 「一覧を見る」ボタン、スマホのタブバー、Online Shopピル、ヘッダーの円形アイコン、お知らせタブ。文字は Text Main を使用)
* **Background (背景・ミルクホワイト):** `#FCFAF6` / `--color-bg` (例: 牛乳のようなウォームホワイト。純白 `#FFFFFF` はカード内・CTAボタン・矢印の円・円形MENUボタンのみ)
* **Background Sub (セクション背景):** `#F4EEE5` / `--color-bg-sub` (例: カード・帯・情報整理型フッター・ドロワーの背景)
* **Background Alt (下層ページ用の中間トーン):** `#EADFD0` / `--color-bg-alt` (例: ラテのようなベージュ。こだわり・店主紹介・店舗情報など、白だと単調なセクションに使用)
* **Background Dark (ダーク背景):** `#2B1D18` / `--color-bg-dark` (例: 焙煎豆に近い暗褐色。ヒーローB、夜営業・特集の帯に使用)
* **Text Main (本文テキスト):** `#3A241B` / `--color-text` (例: 黒に近い濃い茶色。純黒 `#000000` は使わない)
* **Text Muted (薄いテキスト):** `#6B5B51` / `--color-text-muted` (例: 温かみのあるグレーブラウン。価格・日付・パンくず・補足・ラベル用。Background Alt 上でも 4.5:1 を満たす)
* **Text On Dark (ダーク背景・写真上の文字):** `#F5EFE6` / `--color-text-on-dark`
* **Border (境界線):** `#CDBFAE` / `--color-border` (例: ミルクティー色の薄い線。リストの区切り、タグ・円形CTAの縁、短い罫線に使用)
* **Overlay (写真上の暗幕):** `rgba(0,0,0,0.4)` / `--color-overlay`

## 3. タイポグラフィ (Typography)
見出しには上品さと温かみを出すため明朝体を、本文・ナビには可読性を優先して字間を広めにしたゴシック体を使用する。全体に「細く、字間が広く、静か」な印象を保つ。
* **フォントファミリー（見出し・和文明朝）:** `"Shippori Mincho", "游明朝", "Noto Serif JP", serif`
* **フォントファミリー（本文・和文ゴシック）:** `"Zen Kaku Gothic New", "Noto Sans JP", "Hiragino Kaku Gothic ProN", sans-serif`
* **フォントファミリー（英数字・セリフ）:** `"Cormorant Garamond", "EB Garamond", "Noto Serif JP", serif`（店名ロゴ、「Since 20XX」、ナビの「Home」「Menu」、セクション見出しの英字など上品に見せたい欧文にのみ使用）
* **フォントファミリー（英数字・サンセリフ）:** `"Jost", "Noto Sans JP", sans-serif`（ユーティリティナビ「ITEM / CART / MENU」、「Online Shop」、「Scroll」、日付、フッターのコピーライト、電話番号、ラベル見出しの英字にのみ使用）
* **ベースフォントサイズ:** `16px` (1rem)
* **見出し 1 (h1・トップのヒーロー):** `3rem` (48px), `line-height: 1.4`, `font-weight: 500`, `letter-spacing: 0.08em`
* **ページタイトル (h1・下層ページ):** `2.25rem` (36px), 明朝体, `line-height: 1.4`, `font-weight: 400`, `letter-spacing: 0.12em`。パンくずを右上に置くページでは右揃え、置かないページでは中央揃え（または2カラムの左列）にする（例: 「お知らせ」「商品情報」）
* **見出し 2 (h2):** `2rem` (32px), `line-height: 1.5`, `font-weight: 400`, `letter-spacing: 0.08em`（商品紹介・理念などの見出し）
* **見出し 3 (h3・カード見出し):** `1.25rem` (20px), `line-height: 1.6`, `font-weight: 500`, `letter-spacing: 0.06em`
* **キャッチコピー:** `1.25rem` (20px), 明朝体, `font-weight: 400`, `letter-spacing: 0.2em`, 中央揃え。ひらがな主体の短い一文にする（例: 「木漏れ日の下で、ゆっくり一杯。」）
* **本文 (p):** `1rem` (16px), `line-height: 1.9`, `letter-spacing: 0.05em`。長い読み物（商品の誕生秘話・店の歴史）は**左揃え**にする
* **理念テキスト（中央揃えの物語文）:** 見出し `1.625rem` (26px)・`letter-spacing: 0.15em`、本文 `1.125rem` (18px)・`letter-spacing: 0.15em`。次の2つの型がある
  * 文章型: `line-height: 2.6`。1行は全角20文字前後までとし、意味の切れ目で改行する
  * 詩型: `line-height: 2.1`。1行10〜16文字の短い行を積み、意味のまとまり（連）ごとに1行空ける（例: 「暮らしのなかに／小さな幸せをみつける」）
* **ナビゲーション（縦並びナビ・フッターリンク）:** `0.8125rem` (13px)、フッターリンクは `0.9375rem` (15px)、ゴシック体, `letter-spacing: 0.15em`
* **ユーティリティナビ（アイコン付き）:** `0.875rem` (14px), Jost, 大文字, `letter-spacing: 0.12em`, `font-weight: 500`。スマホのタブバーでは `0.75rem` (12px)
* **日付:** `0.9375rem` (15px), Jost, `letter-spacing: 0.05em`, Text Muted（例: `2026.09.11`）
* **タグ（お知らせの分類）:** `0.8125rem` (13px), ゴシック体, Text Main
* **パンくず:** `0.875rem` (14px), ゴシック体, `letter-spacing: 0.05em`
* **価格:** 数字と「円」を `1.125rem` (18px)・Text Muted、「（税込）」を `0.875rem` (14px)・Text Muted にする（例: `650円（税込）`）
* **セクション見出し（英字＋和文サブタイトル・商品一覧などの大見出し）:**
  * 英字: Cormorant Garamond, `1.625rem` (26px), 大文字, `letter-spacing: 0.1em`, `font-weight: 600`, Primary
  * 和文サブタイトル: `1rem` (16px), ゴシック体, `letter-spacing: 0.15em`, 直下に近接配置（余白 `spacing-1`）
  * 例: `SWEETS / 商品情報`、`COFFEE / コーヒー`
* **ラベル見出し（英字ラベル＋和文サブタイトル）:** ストーリー系のセクション（こだわり・焙煎・店主紹介など）で使用。
  * 英字ラベル: `0.875rem` (14px), Jost, 大文字, `letter-spacing: 0.2em`, `font-weight: 500`, 明るい背景では Text Muted、ダーク背景では Secondary（ゴールド）
  * 和文サブタイトル: `1.125rem` (18px), 明朝体, 直下に近接配置（余白 `spacing-1`）
  * 例: `STORY / 木漏れ日のはじまり`、`ROASTER / 焙煎士のこと`
* **縦書き:** `writing-mode: vertical-rl` はロゴ表記・ロゴ下の説明文・「Scroll」「PAGETOP」などの装飾的な短い語（12文字以内）にのみ使用。本文には使わない
* **和文の詰め:** 明朝体の見出しには `font-feature-settings: "palt"` を併用し、字間は上記のとおり少し広げる。理念テキストと2行見出しは `text-wrap: balance` と `line-break: strict` を指定する

## 4. スペースとレイアウト (Spacing)
余白や配置は、以下の8pxグリッドシステム（ベースは4px）を基準に設定してください。写真を主役にするため、セクション間の余白は広めに取る。
* `px` (Padding/Margin): `4px`
* `spacing-1` (最小の余白): `8px`
* `spacing-2` (標準的な余白): `16px`
* `spacing-3` (セクション間の余白): `48px`
* `spacing-4` (大きな余白・写真前後): `96px`
* **コンテンツ最大幅:** `1200px`（テキスト・カードの領域）。写真はこの制限を超えてフルブリードにしてよい
* **スマホの基準幅:** `390px`。この幅で設計・確認する。本文・見出しの左右余白は `24px` を基本とし、写真だけは左右 `0`〜`px`（4px）のほぼフルブリードにする
* **レイアウト方式:** CSS Grid を優先し、写真をフルブリード（画面幅いっぱい）または画面下端まで突き抜けるように配置するセクションを積極的に用いること。左右対称にこだわらず、**「左に細いロゴ列・中央に大きな写真・右にナビ列」のような非対称な構成**を基本とする。
* **トップページのヒーロー基本グリッド（デスクトップ）:** `grid-template-columns: minmax(240px, 20%) 1fr minmax(160px, 12%)`（左＝ロゴ列、中央＝写真、右＝ナビ列）
* **下層ページのグリッド（デスクトップ）:**
  * 左端に幅 `56px` の縦書きロゴ列を固定し、本文領域はその右側から始める
  * 「見出し左＋リスト右」の2カラム（お知らせなど）: `grid-template-columns: minmax(200px, 1fr) 2fr`、右列（リスト）の最大幅は `840px`
  * 理念テキストなど中央揃えの読み物: 幅 `max-width: 22em` の1カラムを画面中央に置く
  * 商品紹介: 左にテキスト（最大幅 `32em`）、右に大きな商品写真の2カラム
* **セクション間:** デスクトップは `spacing-4`、モバイルは `spacing-3` を基本とする。写真の前後は必ず `spacing-4`（モバイルは `spacing-3`）以上あける
* **リスト行の余白:** 上下 `40px`（8pxの倍数）、モバイルは `24px`

## 5. コンポーネントスタイル (Components)
* **ボタン (Button):**
  * メインボタン: 角丸 `999px`（やさしい印象のピル型）、パディング 縦 `14px`・横 `32px`、背景 Primary（深煎りブラウン）、文字色 Text On Dark、シャドウ `none`。ホバー時は背景色を `#6B4234` に変化させ、`transition: 0.3s`
  * サブボタン（ゴースト）: 背景透明、`1px solid` Primary、文字色 Primary。ホバー時に背景 Primary・文字 Text On Dark へ反転
  * **ソフトボタン（Cream Pill・下層ページの主要リンク）:** 背景 Cream、文字 Text Main、角丸 `999px`、パディング 縦 `16px`・左 `28px`・右 `16px`。右端に直径 `28px` の白い円（`#FFFFFF`）を置き、中に黒い右向き三角「▶」（`10px`）を入れる。例: 「一覧を見る ▶」「商品一覧へ ▶」。ホバー時は背景を `#E8DBB8` に、矢印の円を `4px` 右へ動かす（`0.3s`）
  * **コンパクトアウトラインボタン（フッター用）:** 背景透明、`1px solid` Text Main、角丸 `6px`、パディング 縦 `10px`・横 `16px`、Jost・大文字・`0.875rem`、右端にアイコン（`18px`）。例: `CART 🛒` `MY PAGE 👤`
  * テキストリンク: 文字色 Primary、下線は `1px`。ホバーで下線が左から右へ伸びる（`0.3s`）
* **円形アウトラインCTA (Circle Outline CTA):**
  * 直径 `200px`（モバイル `128px`）の円を `1px solid` Border の細い線だけで描く。中央にラベル（`0.875rem`, `letter-spacing: 0.15em`, Text Main）、その `8px` 下に直径 `8px` の Accent（レッド）の点を置く。例: 「メニュー一覧」
  * 商品・メニューのセクション右上に配置し、直下の写真タイルの1行目へ少し重ねる（`z-index` を上にし、円内は Background 色で塗る）
  * ホバー時: 背景 Primary、文字 Text On Dark、点は白に変化（`0.3s`）
* **固定ピルボタン (Fixed Pill CTA / スマホ・ブランド下層ページ):**
  * 画面右上に固定（`top: 16px`・`right: 16px`）する Cream のピル。高さ `44px`、パディング横 `20px`、Jost の `0.9375rem` の文字＋カートアイコン（`18px`）、間隔 `8px`。例: `Online Shop 🛒`（通販がない場合は「予約する」など）
  * 影は付けない。スクロールしても常に表示する
* **円形MENUボタン (Floating Menu Button / スマホ・ブランド下層ページ):**
  * 画面右下に固定（`right: 16px`・`bottom: 16px`＋`env(safe-area-inset-bottom)`）する直径 `64px` の白い円（`#FFFFFF`）。上に2本線のアイコン（`24px`）、下に「MENU」（Jost・`0.75rem`・`letter-spacing: 0.1em`）。タップでドロワーメニューを開く
  * 写真や文字の上に浮くため、このボタンだけ `box-shadow: 0 2px 12px rgba(0,0,0,0.15)` を許可する（他の要素は影なし）
  * 回転バッジと同じ位置になるため、**回転バッジのあるページ（ヒーローA）では使わない**
* **ロゴ表記 (Logo Lockup):**
  * 縦積み構成: ①ゴールドの楕円枠のエンブレム → ②英字店名（Cormorant Garamond, `letter-spacing: 0.3em`, Primary）→ ③和文店名（明朝体・太字・Primary）→ ④「Since 20XX」（小さく）→ ⑤Accent（レッド）の筆記体風スウォッシュ（任意）
  * 配置: 明るい背景（ヒーローA・下層ページの冒頭）では左上に配置。全画面写真（ヒーローB）では中央上部に配置し、文字は Text On Dark にして「公式オンラインショップ」のような小さな説明文を明朝体で直下に添えてもよい
  * 縮小しても要素を減らさない（スマホでも Since とスウォッシュを残し、全体を幅 `96px` 程度に縮小する）
* **横組みロゴ (Horizontal Logo / フッターA):** エンブレムの右に和文店名（太字・Text Main）を横に並べた形。高さ `40px`。SNSアイコンの下に置く
* **縦書きロゴ (Vertical Logo・下層ページ):**
  * 和文店名を縦書き（`writing-mode: vertical-rl`）にして配置する。デスクトップでは画面左端に固定（`left: 16px`, `top: 16px`, 幅 `40px` 前後）し、その下に説明文（例: 「珈琲とお菓子の店」`0.75rem`, `letter-spacing: 0.2em`）を縦書きで添える
  * スマホでは説明文を省き、ページ先頭の左上に高さ `96px` 程度で置く。**固定せず、スクロールで流れて消える**
  * 色は Primary（暗い写真の上では Text On Dark）。トップページへのリンクとし、`alt` に店名を入れる
* **ナビゲーション（デスクトップ・縦並び）:**
  * 右側の列に右揃えで縦に並べる。項目間の余白は `28px` 程度
  * 現在地の項目は Cormorant Garamond で表記し、右に `8px` のドット（Primary）を付ける。それ以外はゴシック体
  * 外部リンクには `12px` の外部リンクアイコンを付ける
  * ホバー時: 文字色を Primary に、`transition: 0.3s`
  * **Menuリンク（コンパクト版・スマホ標準）:** 「Menu」（Cormorant Garamond, `0.875rem`, `letter-spacing: 0.1em`, 下に `1px` の下線）だけを右上に置く。クリックでドロワーメニューを開く。デスクトップでも文章を読ませるページでは縦並びナビの代わりに使える
* **ユーティリティナビ（アイコン付き・デスクトップ）:**
  * 右上に横並び。「英字ラベル＋アイコン」を1セットとし、例は `ITEM / CART / MYPAGE / MENU`（MENUは3本線アイコン）
  * **写真の上（ヒーローB）:** アイコン（`20px`）を白で表示し、各セットの間を高さ `40px` の縦線（`1px`, `rgba(255,255,255,0.5)`）で区切る
  * **明るい背景（下層ページ）:** アイコンを直径 `40px` の Cream の円の中に置き（アイコンは Text Main・`18px`）、ラベルは円の左に `12px` あけて配置。セット間の余白は `32px`。縦線は使わない
  * 円形アイコンには `aria-label` を付ける（ラベル文字がある場合も重複しないよう `aria-hidden` を調整）
* **タブバー (Tab Bar / スマホ・ショップページ):**
  * 画面上部に固定する高さ `64px` の帯。Cream の4つのセル（`ITEM / CART / MYPAGE / MENU`）を均等幅で並べ、各セットは上にアイコン（`24px`）、下にラベル（Jost・大文字・`0.75rem`）を縦に積む。セルの間は `1px` の白い縦線で区切る
  * 左端に幅 `30%` 程度の白いセルを置き、お知らせリンクを2行で入れる（太字 `0.8125rem`・2行目に下線。例: 「本日の営業時間／確認はこちら」）
  * 帯の背景は写真の上でも Cream のまま透過させない。ロゴは帯の左上（ヒーロー上では帯の左側の余白）に置く
* **お知らせタブ (Notice Tab / デスクトップ):**
  * 画面右上の角に固定する長方形の帯（高さ `36px`、背景 Cream、パディング横 `16px`）。左に円形の再生アイコン（`20px`）、右に太字 `0.875rem` のテキスト（例: 「本日の営業時間・臨時休業はこちら」）
  * 一番上に置き、ヘッダー本体はその下から始める
* **パンくず (Breadcrumb):**
  * 「ホーム 〉 現在のページ」の形で、ページの右上（ヒーローCでは写真の右上、白背景ではページタイトルの上）に右揃えで置く
  * 現在のページは Text Main・太字・`1px` の下線、それ以外は Text Muted。区切りは細い「〉」アイコン（`12px`）。写真の上では全体を Text On Dark にする
  * `<nav aria-label="パンくずリスト">` で囲み、現在のページに `aria-current="page"` を付ける
* **写真セクション A：アーチ型ヒーロー (Photo Hero A / トップページ標準):**
  * 写真の上部だけを大きく丸く切り抜く（`border-radius: clamp(96px, 20vw, 320px) clamp(96px, 20vw, 320px) 0 0`）。下端は画面下まで突き抜ける
  * 背景は Background。写真上に文字を載せず、キャッチコピーは写真の上の余白（中央上部）に置く
  * 写真は明るいハイキーのものを使用する
* **写真セクション B：フルブリードヒーロー (Photo Hero B / トップのムーディー版・ショップ・特集):**
  * 画面幅・高さいっぱい（`100svh`）のフルブリード表示。複数枚のスライダーにできる
  * 上部に薄い黒のグラデーションオーバーレイ（`linear-gradient(to bottom, rgba(0,0,0,0.4), rgba(0,0,0,0) 45%)`）を重ね、白文字の可読性を確保
  * ヘッダーは写真の上に透過で重ね、スクロール後は Background 色の固定ヘッダーに切り替える
  * **スライドのタイトル:** 各スライドの左下に、カテゴリー名などを白い明朝体（`2rem`・`letter-spacing: 0.1em`）で表示する（例: 「季節のスイーツ」）。スライド全体をそのカテゴリーページへのリンクにする
  * 見出しテキストを載せる場合は写真中央〜下部に明朝体で大きく配置
* **写真セクション C：ページヒーロー (Photo Hero C / 下層ページの導入):**
  * 静止した1枚の写真を全画面（スマホは `100svh`、デスクトップは `70vh` 以上）に表示する。落ち着いたライフスタイル写真（窓辺で本を読む人・カップと焼き菓子など）を使う
  * Overlay（`rgba(0,0,0,0.4)`）を重ね、ページタイトル（白・明朝体・`2.25rem`・`letter-spacing: 0.12em`）を写真の中央に配置する。左上に縦書きロゴ、右上にパンくずを置く
  * 写真の直後の余白は `spacing-3`〜`spacing-4` とし、続けて理念テキストブロックなどの本文セクションを置く
* **ヒーローの使い分け:** ヒーローA と ヒーローB は**1ページ内で併用しない**（トップページはどちらか1つ）。下層ページの導入にはヒーローCを使う
* **回転バッジ (Circular Badge):**
  * 円周に沿って英字（例: `New Menu / Seasonal / `）を繰り返し配置し、中央に和文（例: 「新メニュー」明朝体 `1rem`）を置く
  * サイズ: デスクトップ `170px`、モバイル `96px`。画面右下に固定（余白 `24px`、モバイルは `16px`）。スマホでは写真の右下に半分ほど重なって見えてよい
  * 円周の文字だけが `24s linear infinite` でゆっくり回転する。中央の和文は静止。円周の文字は Cormorant Garamond の `0.75rem`, `letter-spacing: 0.15em`
  * 背景: Background（不透明度90%）＋ `backdrop-filter: blur(4px)`。文字色は Primary
  * リンク先は新メニュー・季節限定ページ。スクリーンリーダー向けに `aria-label="新メニューを見る"` を付け、円周の文字は `aria-hidden="true"` にする
* **スクロールインジケーター (Scroll Indicator / ヒーローB・デスクトップのみ):**
  * 左端の縦中央に、縦書きの「Scroll」（Jost, `0.75rem`, `letter-spacing: 0.2em`, Text On Dark）と、その下に長さ `64px`・太さ `1px` の縦線を置く。縦線は上から下へ伸びるアニメーション（`2s`）を繰り返す
* **スライダーのページネーション (Slider Dots / ヒーローB):**
  * 右下に横並び（スマホでも右下のまま）。非選択は `8px` の円（白・不透明度50%）、選択中は `14px` のリング（`2px` の白い縁）の中に `6px` の白い点
  * 自動切替は `6s` 間隔、切替は `1.2s` のクロスフェード
* **セクション見出し (Section Title):**
  * 「タイポグラフィ」のセクション見出し（Cormorant Garamond の大文字英字＋和文サブタイトル）を、メニュー・商品一覧の大見出しに使用する。左揃えで、右側に円形アウトラインCTAを置く構成を基本とする
* **ラベル見出し (Label Heading):**
  * 「タイポグラフィ」のラベル見出しパターンを、ストーリー系セクションの見出しに使用する（左揃えまたは中央揃え。1ページ内で統一）
* **理念テキストブロック (Message Block):**
  * 中央揃え、幅 `max-width: 22em`。見出し（例: 「コーヒーで、まちをやさしくしたい。」）→ 本文の順に、意味のまとまりごとの短い段落（または詩型の連）を `spacing-3` 間隔で縦に並べる
  * ロゴ・ラベル見出し以外の装飾は置かない。背景は Background
  * **スクロール連動の表示（文章型のみ）:** 段落は画面に入る前は `opacity: 0.25`、画面中央に近づくにつれ `1` へ変化させる（文字色は Text Main のまま不透明度だけを変える）。`prefers-reduced-motion: reduce` では最初から `opacity: 1` にする
  * 詩型は動きを付けず、ヒーローCの直後に置く。見出し（h2）は明朝体・`letter-spacing: 0.1em`
* **カード (Card / メニューカード):**
  * 背景: `#F4EEE5` (Background Sub)
  * 角丸 (border-radius): `16px`
  * 境界線: `1px solid [Border Color]`
  * 影 (box-shadow): `none`（境界線と背景色の差で区切りを表現する）
  * 写真: カード幅いっぱいに配置し、上部に大きく見せる（比率 4:3 以上）。ホバー時は写真がゆっくり `scale(1.03)`（`0.6s`）
  * カード内の余白: `spacing-2`
  * カード配置: モバイル1〜2列、タブレット2列、デスクトップ3列。カード間の余白は `spacing-2`〜`spacing-3`
* **フォトタイル (Photo Tile / トップページの商品一覧):**
  * 枠線・背景色・角丸・影のない、正方形（1:1）の写真だけのタイル。写真の背景色は `#FAF7F2` 前後のウォームホワイトで揃える
  * デスクトップ3列・タブレット2列・モバイル1列。デスクトップの列間は `spacing-3`、左右の余白は `spacing-2`〜`spacing-3` とし、ほぼフルブリードで並べる。モバイルは左右 `8px` の余白で、タイルの縦の間隔は `spacing-3` 以上あける
  * タイルの下に商品名・価格（メニュー価格表示のルール）を、写真の左端にそろえて置く。ホバー時は写真が `scale(1.03)`（`0.6s`）
  * 落ち着いた一覧は「カード」、写真を主役にしたい導入は「フォトタイル」と使い分ける
* **商品リスト行 (Product Row / スマホの商品一覧):**
  * 左に4:3のサムネイル（幅 `55%`）、右に商品名（`1.125rem`・Text Main・縦中央揃え）を置く横並びの行。行と行の間は `spacing-2`〜`spacing-3`。長い名前は折り返してよい
  * カテゴリー（例: 「期間限定」「コーヒー」「焼き菓子」）ごとに、明朝体 `1.75rem` の見出し（左揃え）で区切る。見出しの上には「見出し罫線」（区切り線の項を参照）を置く
  * デスクトップではカード（3列）に切り替える
* **メニュー価格表示 (Menu Item):**
  * カード・フォトタイルの写真の下に、商品名（本文サイズ・Text Main）→ 価格（Text Muted）の順で縦に並べる。補足説明は1行までとする
  * 価格は「650円（税込）」のように税込表記を基本とし、大きさは「タイポグラフィ」の価格の規定に従う
  * 「NEW」「季節限定」などのチップは写真左上に小さく重ねる（背景 Accent、文字 白、角丸 `999px`、`0.75rem`）
* **商品紹介セクション (Product Feature / メニュー詳細):**
  * デスクトップは2カラム構成。左にテキスト（h2 → 本文 3〜4行 → ソフトボタン、縦位置は中央）、右に大きな商品写真を置き、写真は右端へ寄せてはみ出させてよい。セクションの高さは `560px` 以上
  * 背景: 放射状グラデーション（`radial-gradient(ellipse at 70% 50%, #FFFFFF 0%, #F4EEE5 100%)`）。商品写真は白背景の切り抜きとし、`mix-blend-mode: multiply` を指定して背景に自然に馴染ませる
  * 複数の商品を並べる場合はセクションを縦に積み、左右の配置を交互に入れ替える
  * スマホは縦積み（写真 → 見出し → 本文 → ソフトボタン）。見出しは中央揃え・2行まで、本文は左揃え
* **ロースター（店主）紹介ブロック (Roaster / Owner Block):**
  * 写真＋右側にテキストの2カラム構成（モバイルでは縦積み）
  * 写真はカラーのまま使い、上部をアーチ型に切り抜く（Photo Hero Aと同じ丸み）。手元（焙煎・ドリップ）の写真を優先する
  * ラベル見出し（英字ラベル＋和文サブタイトル）パターンをタイトルに使用
  * 背景は Background Alt
* **カテゴリーフィルター (Category Filter):**
  * ピル型ボタン（`border-radius: 999px`）、境界線のみでシャドウなし
  * 未選択時: 背景透明・Border色の線・文字 Text Main、選択時: 背景Primary（深煎りブラウン）・文字 Text On Dark
  * 項目例: `ALL / COFFEE / SWEETS / FOOD / TAKE OUT`
  * メニュー一覧ページの最上部、見出し直下に配置。モバイルでは折り返さず横スクロール（スナップあり）にする
* **お知らせリスト (News List):**
  * デスクトップは「見出し左＋リスト右」の2カラム。左列にページタイトル（h1）とソフトボタン「一覧を見る ▶」を縦に並べ、左列の縦位置はリストの中央あたりにそろえる
  * 各行（上下 `40px`）は2段構成。上段に日付（Jost・Text Muted）とタグ、下段にタイトル（`1.125rem`・Text Main）
  * タグ: `1px solid` Border、角丸 `4px`、パディング 縦 `2px`・横 `8px`、背景透明。複数のタグは `8px` あけて横に並べる。例: 「営業日について」「重要なお知らせ」「新メニュー」
  * 行の区切り: 下に `1px solid` Border（Background Alt の上では点線。「区切り線」を参照）
  * **ホバー時:** 行の下線を Text Main に変え、タイトルに下線を引く（`0.3s`）。キーボードフォーカス（`:focus-visible`）でも同じ表示にする。行全体をリンクにする
* **区切り線 (Divider):**
  * Background・Background Sub の上では `border-top: 1px solid [Border Color]` の実線を使用する
  * Background Alt のセクション内では、実線ではなく `border-top: 1px dashed [Border Color]` の点線区切りを使用し、手書きのメニュー表のような質感を演出する
  * **短い罫線 (Short Rule):** 幅 `28px`・太さ `1px`・Border 色の短い線。フッターやドロワーで、リンクのグループ（例: メインのリンク／通販／会社情報）を区切るときに使う。上下の余白は `spacing-2`
  * **見出し罫線 (Heading Rule):** カテゴリー見出しの上に置く、全幅 `1px` の Border の線。左から `40%` の長さだけ Text Main の `1px` 線を重ねて濃くする
* **オーバーラップ情報カード (Overlap Info Card):**
  * 店舗情報・アクセスページ向け。上部にテラス席・外観の写真を配置し、その下端にカード（Background Sub、角丸 `16px`）を写真へ少し食い込ませるように重ねて配置する（`margin-top: -spacing-4` 相当。モバイルは `-spacing-3`）
  * カード内の項目（住所・営業時間・定休日・席数・テラス席・駐車場など）は、項目名（Text Muted・小さめ）と内容の間に点線区切り線を挟んで縦に並べる
  * 下部に地図と、電話・Instagramへのボタンを置く
* **写真上のCTAボタン (Floating CTA on Photo):**
  * 「メニューを見る」「予約する」等、写真に重ねて配置する円形（直径 `120px`）または横長ピル型のボタン。写真の右下または中央下に配置する
  * **暗い写真の上**: 背景は白（`#FFFFFF`）、文字は Text Main
  * **明るい写真の上**: 背景は Primary、文字は Text On Dark（写真に負けない高コントラストを優先する）
* **Instagramギャラリー (Gallery):**
  * 正方形（1:1）の写真を隙間 `px`（4px）で並べる。モバイル3列、デスクトップ6列。フルブリード表示
  * 見出しは「INSTAGRAM」（ラベル見出しパターン）。ホバー時に Overlay を重ねて Instagram アイコンを表示
* **ドロワーメニュー (Drawer):**
  * 背景は Background Sub。リンクはゴシック体 `1.125rem`・`letter-spacing: 0.1em`、項目の間隔（ピッチ）は `56px`。グループの間は短い罫線で区切る
  * 上部に「Home」（Cormorant Garamond）、下部に通販リンク（例: `Online Shop 🛒`）、会社情報などのサブリンク、縦書きロゴ、コピーライトを置く。閉じるボタンは右上に置く
* **フッター A：ブランドモチーフ型 (Footer A / トップページ):**
  * 背景は Background。ロゴのスウォッシュ（Accent）を画面幅いっぱいに巨大化した曲線を、左側から下端へはみ出させて配置する（装飾のため `aria-hidden="true"`）。曲線の上には文字を重ねない
  * 右下に情報を寄せる: 左列にリンク（1行目は Cormorant Garamond の「Home」、以降はゴシック体。行間は `40px`）、右列にSNSアイコン（直径 `32px`・Primary の単色・横並び、間隔 `spacing-2`）、その下に「プライバシー設定」ボタン（ピル型・Primary 背景・Text On Dark・`0.8125rem`・太字）、横組みロゴ、コピーライト（Jost・`0.75rem`）
* **フッター B：情報整理型 (Footer B / 下層ページ・ショップ):**
  * 背景は Background Sub。上下の余白は `spacing-4`。リンクのグループを短い罫線または `1px solid` Border の実線で区切る
  * **基本形（ブランドサイト）:** メインリンク（メニュー・店舗情報・お知らせなど）→ 短い罫線 → 通販リンク（`Online Shop 🛒`）→ 短い罫線 → サブリンク（品質への取り組み・会社概要・方針など）→ コピーライト（Jost・大文字・`0.75rem`）。右下に縦書きロゴ（大きめ・幅 `110px` 以上）を置く。右上端には縦書きの「PAGETOP」を置く
  * **ショップ拡張（オンラインショップ）:** 上記に加えて、次の段を実線で区切って足す。①コンパクトアウトラインボタン（`CART` `MY PAGE`）②「ご利用ガイド」（太字の見出し＋リンク）③「お電話でのお問い合わせ」（太字）と電話番号（`tel:` リンク・Jost・下線）、受付時間・休業日（`0.875rem`）、注意書き（太字）④法的リンク（`0.8125rem`）。右上に「PAGETOP ▲」（Jost・`0.875rem`・`letter-spacing: 0.12em`）を置く
* **モーション (Motion):**
  * スクロールで要素がふわっと現れる（`opacity 0→1`・`translateY(24px→0)`・`0.8s ease-out`）。ヒーロー写真は `scale(1.05→1)` を `8s` かけてゆっくり縮める
  * `prefers-reduced-motion: reduce` の環境では、回転バッジ・スライダー自動切替・スクロールアニメーション・理念テキストの濃淡変化をすべて停止する

## 6. レスポンシブ振る舞い (Responsive)
* **モバイルファースト**で設計すること。来店客の多くはスマホで営業時間・場所を確認するため、店舗情報とアクセスは最優先で見えるようにする（トップページのファーストビュー直後に営業時間と「アクセス」ボタンを配置）。基準幅 `390px` で確認する。
* **ブレイクポイント:**
  * スマホ (Mobile): `~ 639px`
  * タブレット (Tablet): `640px ~ 1023px`
  * デスクトップ (Desktop): `1024px ~`
* **ナビゲーション（スマホ・タブレット）:** 縦並びの右ナビ・横並びのユーティリティナビ・左端固定の縦書きロゴ・お知らせタブは `1024px` 以上でのみ使用する。`1023px` 以下では、次の3パターンから選ぶ。**1つのサイトの中では、ブランドページは M1 か M3 のどちらか一方に統一し、通販ページだけ M2 を使ってよい。**
  * **M1（Menuリンク型・明るいトップ／ヒーローAのサイト）:** ロゴを左上に置き、右上に「Menu」の下線付きテキストだけを置く。スクロールしても右上に固定する。タップでドロワーメニューを開く
  * **M2（タブバー型・オンラインショップ）:** 画面上部に固定のタブバー（左に白いお知らせセル、右に Cream の `ITEM / CART / MYPAGE / MENU`）。ヒーローB上では、お知らせリンクを白い太字（下線付き・円形の再生アイコン付き）でタブバーの下の写真上に置き、スクロール後にタブバー左端の白いセルへ移す
  * **M3（円形MENU型・落ち着いたブランドページ）:** 左上に縦書きロゴ、右上に固定ピル（`Online Shop 🛒`）、右下に固定の白い円形MENUボタンを置く。ヘッダーの帯は作らず、写真をそのまま見せる
* **ヒーローA（スマホ）:** ロゴは左上に幅 `96px` 程度で全要素を残して置く。キャッチコピー（`1.125rem`・`letter-spacing: 0.15em`）をロゴの下に中央揃えで置き、写真は左右余白なし〜`px`（4px）で、上部の丸みを `clamp(96px, 30vw, 150px)` として下端まで伸ばす。回転バッジ（`96px`）は写真の右下に重ねる。右上は M1 の「Menu」。
* **ヒーローB（スマホ）:** `100svh` の縦長フルブリード写真。M2 を使う場合はタブバーを、M3 を使う場合は固定ピルと円形MENUボタンを重ねる。スライドのタイトル（`2rem`）を左下、ドットを右下に置く。「Scroll」表示は非表示。
* **ヒーローC（スマホ）:** `100svh`。ページタイトルは写真の中央（`1.75rem`）、左上に縦書きロゴ、右上にパンくず、右下に円形MENUボタン（M3）を置く。
* **カード・フォトタイル・商品リスト・ギャラリー:** カードは1〜2列、フォトタイルは1列（左右 `8px`）、商品一覧のページは商品リスト行、ギャラリーは3列に変更。ロースター紹介と店舗情報は縦積み。円形アウトラインCTAは `128px` に縮小し、セクション見出しの右に置く。
* **お知らせリスト（スマホ）:** 2カラムを1カラムに変更し、見出しを上、リストを下に置く。ソフトボタン「一覧を見る」はリストの下に左揃えで置く。行の上下余白は `24px`、タイトルは `1rem`。
* **商品紹介（スマホ）:** 縦積みにし、写真を上（画面幅いっぱい）、見出し（中央揃え・最大2行）、本文（左揃え・左右 `24px`）、ソフトボタンの順に置く。左右交互の配置は使わない。固定ピルは上に重ねたままにする。
* **理念テキスト（スマホ）:** 見出し `1.5rem`、本文 `1rem`。文章型は `line-height: 2.4`・`letter-spacing: 0.1em`、1行は全角16文字前後を目安にする。詩型は `line-height: 2.1`・`letter-spacing: 0.1em` とする。
* **フッター（スマホ）:**
  * リンクは横並びを廃止し、縦に1列で積み上げる（項目のピッチは `56px`）。
  * **フッターA:** 左にリンクを縦に積み、その下に**右揃え**でSNSアイコン（直径 `40px`）、「プライバシー設定」ボタン、横組みロゴ、コピーライト（2行）を置く。巨大なスウォッシュは最下部の左側に大きく見切れさせる。
  * **フッターB（基本形）:** メインリンク・短い罫線・通販リンク・サブリンクを左に縦積みし、右下に縦書きロゴ（幅 `110px`）、左下にコピーライトを置く。
  * **フッターB（ショップ拡張）:** 最上段は左にメインリンク、右に `PAGETOP ▲` とコンパクトアウトラインボタン（`CART` `MY PAGE` を縦に2つ）を置く。ご利用ガイドのリンクは**2列のグリッド**にする。電話番号は `1.625rem` にして、法的リンクは左に縦積み、右に縦書きロゴを置く。
* **見出しの文字サイズ:** モバイルでは見出し1 (h1) を `2rem` (32px) 程度まで縮小し、見出し2 (h2) は `1.5rem` (24px)、ページタイトルは `1.75rem` (28px) にして、大きな写真の中でも文字が窮屈にならないようにする。

## 7. アクセシビリティ (Accessibility)
* 本文などすべてのテキスト（特に警告やエラーメッセージ）は、背景色とのコントラスト比を `4.5:1` 以上にすること。Secondary（ゴールド）は明るい背景では文字色に使わず、装飾（罫線・アイコン・エンブレム）に限定する。
* 写真上に白文字を重ねる場合は、必ず半透明の黒オーバーレイを敷いてコントラストを確保すること（ヒーローCのタイトル・パンくず・スライドのタイトルを含む）。
* 画像には必ず `alt` 属性を記述すること（メニュー写真は商品名を明記。装飾目的の画像・フッターのスウォッシュは `alt=""` または `aria-hidden="true"`）。
* `<html lang="ja">` を指定し、キーボード操作のフォーカスは `2px` のアウトライン（明るい背景は Primary、ダーク背景は Secondary、`outline-offset: 2px`）を必ず表示する。ホバー時の表示変化（お知らせ行の線・ボタンの色など）は `:focus-visible` でも同じにする。
* ボタン・リンクのタップ領域は `44px × 44px` 以上を確保する。円形アイコンは `40px` の見た目でも、`padding` などで当たり判定を `44px` 以上にする。タブバー（高さ `64px`）と円形MENUボタン（`64px`）はこの条件を満たす。
* 固定表示の要素（タブバー・固定ピル・円形MENUボタン）が本文を隠さないように、`html { scroll-padding-top }` と本文の下余白を確保する。円形MENUボタンは `env(safe-area-inset-bottom)` を加えて配置し、`aria-label="メニューを開く"` を付ける。
* 自動で動くもの（スライダー・回転バッジ）には停止手段を用意し、`prefers-reduced-motion` を尊重する。ナビの現在地には `aria-current="page"` を付ける。
* 理念テキストのスクロール連動の濃淡は、途中の薄い状態で読めなくなるため、`opacity` の下限を `0.25` とし、読み終える位置では必ず `1` になるようにする。スクリーンリーダーには常に全文を読み上げさせる（`display: none` にしない）。
* 縦書きロゴ・縦書きの説明文はリンクの `aria-label`（店名）で意味を伝え、縦書きの文字自体は `aria-hidden="true"` にしてよい。電話番号は `tel:` リンクにする。
* スライダーのタイトルリンクには、リンク先が分かるテキスト（例: 「季節のスイーツ」）を必ず含める。

## 8. エージェントプロンプトガイド (Agent Prompt)
AIエージェントへの指示です。コードを生成する際は、以下のルールを遵守してください。
1. あなたはプロのWebデザイナーです。このデザインシステムに沿って、ポートフォリオとして見栄えのするカフェのWebサイトを作成してください。
2. 上記のトークン（変数名またはカラーコード）をハードコードせず、可能な限りCSS変数またはTailwindのクラスを用いて表現してください。
3. 日本語が不自然にならないよう、文字間隔（`letter-spacing`）や行間を適切に調整してください。特に明朝体見出しとキャッチコピー、理念テキストは字間を広げること。
4. 写真がコンテンツの主役であるため、テキストで説明を埋めすぎず、大きな写真＋短い一言のキャッチコピーという構成を優先してください。
5. 未知のデザイン要素を生成する場合は、事前にユーザーに質問するか、このデザインシステムに準拠した形で提案してください。
6. 下層ページ（こだわり・ロースター紹介・店舗情報など）では、Background だけでなく Background Alt（ベージュ）・Background Sub・Background Dark を使い分け、ページ全体が単調になりすぎないようにしてください。ストーリー系のセクション見出しには「ラベル見出しパターン」を優先的に使用してください。
7. トップページのヒーローは Photo Hero A（アーチ型）か Photo Hero B（フルブリード・スライダー）のどちらか一方を1つだけ使い、混在させないでください。下層ページの導入には Photo Hero C（ページヒーロー）を使います。
8. 参考サイトの構造やトーンは踏襲しても、ロゴ・写真・文言・固有のキャッチコピーをそのまま使ってはいけません。店名・キャッチコピー・メニュー名・お知らせの文面・電話番号はすべて架空店舗のオリジナルで作成してください（電話番号はダミー表記とする）。
9. 写真が用意されていない場合は、比率（4:3、1:1、アーチ型など）を固定した Background Alt 色のプレースホルダーを置き、後から写真へ差し替えやすい構造にしてください。
10. Accent（レッド）は装飾的に使い、1画面あたり1〜2箇所までにしてください（フッターAのブランドモチーフは例外）。使いすぎると上品さが損なわれます。
11. 情報ページ（お知らせ・フッター・店舗情報）は装飾を足さず、余白・`1px` の罫線・Cream 色だけで整理してください。トップは写真で魅せ、下層は静かに読ませることで、ページ間のメリハリをつけてください。
12. スマホ表示を先に実装し、基準幅 `390px` で確認してください。スマホのナビは M1・M2・M3 のいずれかに統一し、PC用のナビ（縦並び・横並び・左端固定ロゴ）を `1023px` 以下に残さないでください。固定表示の要素（円形MENUボタン・回転バッジ）を同じ位置に重ねないでください。
13. スマホで文字が小さくなりすぎないよう、本文は `1rem` を下限にしてください。長い読み物は左揃え、短い理念・詩は中央揃えにしてください。
14. ページ別の推奨構成（この順序を基本とし、必要に応じて調整すること）:
    * **トップ:** ヒーローA → 理念の短文（ラベル見出し）→ 商品一覧（セクション見出し＋円形アウトラインCTA＋フォトタイル）→ ロースター紹介 → Instagramギャラリー → お知らせ（2カラム）→ 営業時間・アクセス → フッターA
    * **想い・こだわり:** ヒーローC（ページタイトル・パンくず）→ 理念テキストブロック（詩型または文章型）→ フルブリード写真 → ロースター紹介 → フッターB
    * **メニュー一覧:** 下層ヘッダー → パンくず・ページタイトル → カテゴリーフィルター → カード（スマホは商品リスト行）→ フッターB
    * **メニュー詳細・商品紹介:** 下層ヘッダー → ページタイトル → 商品紹介セクション（左右交互）→ フッターB
    * **お知らせ:** 下層ヘッダー（デスクトップはお知らせタブ付き）→ お知らせリスト（2カラム）→ フッターB
    * **店舗情報:** ヒーローC または写真 → オーバーラップ情報カード（営業時間・アクセスを最優先）→ 地図 → フッターB
